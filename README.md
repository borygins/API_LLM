# API LLM — практическая работа с DeepSeek и LangChain

Практический проект по интеграции большой языковой модели через API. В Jupyter Notebook собраны сценарии работы с DeepSeek и LangChain: от настройки подключения и анализа токенов до управления генерацией и построения переиспользуемых промптов.

Цель проекта — детально разобраться в поведении LLM и на практике проверить, как параметры модели и структура промпта влияют на результат. Такой подход помогает не только использовать готовый API, но и понимать ограничения модели, диагностировать неожиданные ответы и осознанно выбирать настройки для конкретной задачи.

## Возможности

- подключение к `deepseek-flash` через `ChatDeepSeek`;
- безопасная загрузка API-ключа из переменных окружения;
- включение и отключение режима рассуждений (thinking mode);
- раздельный вывод рассуждений модели и финального ответа;
- сравнение результатов при разных значениях `temperature` и `top_p`;
- ограничение длины ответа с помощью `max_tokens`;
- подсчёт и анализ токенов через `tiktoken`;
- создание переиспользуемых промптов с `PromptTemplate`;
- работа с системными и пользовательскими сообщениями через `ChatPromptTemplate`;
- применение Zero-Shot, One-Shot и Few-Shot prompting.

## Запуск проекта

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/borygins/API_LLM.git
   cd API_LLM
   ```

2. Создайте и активируйте виртуальное окружение:

   **Windows (PowerShell):**

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   **Linux/macOS:**

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Создайте файл `.env` на основе шаблона:

   **Windows (PowerShell):**

   ```powershell
   Copy-Item .env.example .env
   ```

   **Linux/macOS:**

   ```bash
   cp .env.example .env
   ```

   Затем укажите в `.env` свой API-ключ DeepSeek:

   ```dotenv
   DS_API=your_deepseek_api_key
   ```

5. Откройте `main.ipynb` в Jupyter Notebook или VS Code и последовательно выполните ячейки.

> Файл `.env` исключён из Git. Не публикуйте настоящий API-ключ в репозитории или выводе ноутбука.

## Пример использования

```python
import os

from dotenv import load_dotenv
from langchain_deepseek import ChatDeepSeek

load_dotenv()

llm = ChatDeepSeek(
    model="deepseek-flash",
    api_key=os.getenv("DS_API"),
    max_retries=3,
)

response = llm.invoke("Расскажи короткий интересный факт об атмосфере Земли")

print(response.content)
```

## Режим рассуждений

DeepSeek может возвращать ход рассуждений отдельно от итогового ответа:

```python
response = llm.invoke("Почему небо голубое?")

reasoning = response.additional_kwargs.get("reasoning_content")

print("Рассуждения:", reasoning)
print("Ответ:", response.content)
```

Режим можно отключить для отдельных экспериментов:

```python
regular_llm = llm.bind(
    extra_body={"thinking": {"type": "disabled"}}
)
```

## Инженерный фокус

Репозиторий демонстрирует системный подход к работе с LLM API: безопасную конфигурацию окружения, исследование структуры ответа модели, анализ токенов, настройку параметров генерации и проектирование промптов под разные сценарии.

Особое внимание уделено не только получению ответа от модели, но и пониманию происходящего внутри интеграции: почему результат меняется, как диагностировать пустой или обрезанный ответ, чем отличается режим рассуждений и когда стоит использовать разные техники промптинга. Формат ноутбука позволяет сохранять код, пояснения и наблюдаемые результаты в одном воспроизводимом рабочем процессе.
